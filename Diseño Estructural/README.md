### Generación de Diagramas de Interacción P-M (Flexión Biaxial)

Solver numérico para el diseño de columnas de hormigón armado con secciones transversales de geometría arbitraria. El algoritmo utiliza geometría computacional (librería Shapely) para calcular dinámicamente el área y centroide del polígono de compresión bajo cualquier ángulo de eje neutro, permitiendo obtener la superficie de falla completa (3D) y sus proyecciones 2D. **[Código.](./solver_biaxial_seccion_arbitraria.ipynb)**
